# C-digo_JavaScript_CSS_HTML
Código para cálculo de média escolar 

Médias Escolares
Projeto desenvolvido para praticar conceitos fundamentais de HTML, CSS e JavaScript, criando uma aplicação simples para calcular a média de quatro notas escolares e informar o status do aluno.

 Sobre o projeto
A aplicação permite inserir quatro notas, calcular automaticamente a média e identificar a situação do aluno de acordo com a média obtida.

O projeto também possui validação dos campos, destacando os campos que não foram preenchidos corretamente.

 Regras de aprovação
Média	Status
≥ 7.0	🟢 Aprovado
≥ 5.0 e < 7.0	🟠 Exame
< 5.0	🔴 Reprovado

Funcionalidades
Inserção de quatro notas.
Cálculo automático da média.
Exibição da média com uma casa decimal.
Identificação do status do aluno.
Validação dos campos de notas.
Destaque visual para campos não preenchidos.
Botão para limpar todas as informações.
Interface com layout moderno.


 Tecnologias utilizadas
HTML5 — estrutura da aplicação.
CSS3 — estilização e layout.
JavaScript — validação, cálculo da média e alteração dinâmica do conteúdo da página.

 Como executar
Baixe ou clone este repositório.
Abra o arquivo index.html em um navegador.
Digite as quatro notas.
Clique em Calcular Média para visualizar o resultado.
Não é necessário instalar dependências para executar o projeto.
